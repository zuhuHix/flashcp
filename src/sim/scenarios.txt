# Real end-to-end measurements the simulator is calibrated and validated against.
# Every number was measured on the physical drive (sources: merged PR bodies, `gh pr view N`).
# One scenario per line, space-separated key=value; `,` separates list items in args/env.
#
#   id      unique name (drive prefix: sd- SanDisk Cruzer Blade 8 GB USB 2 BOT, msi- MSI DATAMAG UAS)
#   drive   sandisk | msi (the built-in profile name is sandisk-cruzer-usb2 / msi-datamag-uas)
#   op      build | add | pull | micro (micro = a synthetic probe-like trace, see `kind`)
#   data    dataset to write/read: small | smallB (small, seed 7) | many | mixed | file512m | none
#   layout  what the image holds before the op:
#             blank            nothing (build)
#             mkfs<C>          mkfs.exfat -c <C> (empty volume), e.g. mkfs32k
#             flashcp:<D>[:<C>] `flashcp build <D>` (optionally --cluster <C>)
#             kernel<C>:<D>    mkfs.exfat -c <C> + `flashcp add <D>` with FLASHCP_TEST_NO_ADD_BUILD
#                              (approximates a kernel `cp -r` layout: no root/loop mount needed)
#   args    extra flashcp arguments (comma-separated), env  extra environment (comma-separated)
#   real    measured seconds (median where runs ≥ 3; mid-range where only a range is known)
#   lo,hi   measured range when known (run-to-run spread)
#   src     where the number comes from
#   pairs   validated rankings are listed at the end as `pair faster=<id> slower=<id>`
#
# micro scenarios (from `flashcp probe` on the drive): kind=seqw|randw|flush|seqr, bs=<bytes>,
# qd=<n>, bytes=<total>; `real` is the time those bytes took at the measured rate.
